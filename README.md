# 📊 Marketing Data Analysis

## 📌 Project Overview

This project analyzes marketing campaign performance using Microsoft Excel.

The goal is to transform raw marketing data into meaningful insights that can support better business decisions. The project follows a complete data analytics workflow:

**Collect → Prepare → Clean → Analyze → Visualize → Present**

## 🎯 Project Objectives

The main objectives of this project are to:

* Analyze marketing campaign performance
* Evaluate marketing budgets and leads
* Measure conversions and conversion rates
* Compare performance across marketing channels
* Compare regional performance
* Analyze performance across years and months
* Create meaningful visualizations and KPIs
* Build an interactive marketing dashboard
* Generate data-driven findings and recommendations

## 📊 Dataset Introduction

The dataset contains **300 marketing campaign records** and **7 variables**.

### Main Variables

| Variable    | Description                |
| ----------- | -------------------------- |
| Campaign_ID | Unique campaign identifier |
| Start_Date  | Campaign start date        |
| Channel     | Marketing channel          |
| Region      | Campaign region            |
| Budget      | Marketing budget           |
| Leads       | Number of generated leads  |
| Conversions | Number of conversions      |

The dataset is used to evaluate marketing spending, lead generation, conversions, and overall campaign efficiency.

---

## 🧹 Data Preparation & Cleaning

The raw dataset was preserved before cleaning.

The cleaning process included:

* Removing duplicate records
* Handling missing or invalid dates
* Standardizing blank and unknown categories
* Handling missing numerical values
* Standardizing text values
* Preparing clean data for analysis

The project identified **7 duplicate records** and **16 rows with missing/invalid Start_Date values** during preparation.

## 🔍 Key Findings

The analysis produced several important findings:

1. **Search** generated the highest conversion volume, with approximately **8,170 conversions** and a **23.3% conversion rate**.

2. **Mogadishu** had the highest budget and conversion volume.

3. **Bosaso** recorded a strong conversion rate of approximately **24.0%**.

4. **Radio** had the lowest named-channel conversion rate, at approximately **10.9%**.

5. The **2026 conversion rate (20.7%)** was higher than the **2025 conversion rate (17.9%)**.

---

## 💡 Recommendations

Based on the analysis:

### 1. Invest Strategically

Increase investment in high-performing channels such as **Search**, while continuing to monitor efficiency.

### 2. Reassess Radio

Review Radio campaigns and identify opportunities to improve conversion efficiency before increasing spending.

### 3. Replicate Successful Strategies

Apply successful practices from high-efficiency regions such as **Bosaso and Garowe**.

### 4. Scale Carefully

Continue high-volume marketing activity in **Mogadishu** while protecting conversion efficiency.
